# Change Log

All notable changes to this project will be documented in this file.

## Version 1.0.0 - May 6th, 2025

- Initial release of the project.
- Added core functionality and features.

## Version 1.1.0 - June 10th, 2025

- Refactored codebase for better maintainability and readability.
- Improved performance of the rendering process.
- Restructured the component to `./components/` for better organization.

## Version 1.2.0 - July 15th, 2025

- Added new `onRendererUpdated` event to notify when the renderer has been updated.
- Added new `onError` event to handle errors during rendering.

## Version 1.3.0 - August 12th, 2026

- Added new `devicePixelRatio` property to support high-DPI displays.
- Added new `frameRate` property to control the rendering frame rate.
- Update the debug panel to display the current frame rate and device pixel ratio.
- Update the styles of the debug panel to improve readability and usability.

## Version 1.3.1 - August 12th, 2026

- Docs only: rewrote the README to be short and npm-friendly (install + minimal getting-started example).
- Added a "Why 'three-next' not 'R3F'?" section covering customization, shader initialization, FPS capping, weight, and debuggability.
- Moved the full API reference (architecture, prop tables, hooks, error-handling flow) to `docs/API.md`.
- No code changes.
